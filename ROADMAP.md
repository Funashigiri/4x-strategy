# Дорожная карта

Игра развивается **бесконечно**: год за годом становится глубже и проработаннее. Финишной черты нет — есть этапы, после которых игра заметно меняется. Ближние этапы расписаны подробно, дальние — крупно и будут уточняться.

## Видение

- **Много рас** — не только люди. У каждой расы свой характер, бонусы и уникальные юниты.
- **Эпохи от древности до космоса — и дальше.** Начинаем с племени на одной планете, заканчиваем… не заканчиваем.
- **Только одиночная игра**: игрок против ИИ. Мультиплеера не будет — поэтому ИИ — ключевая система, а не дополнение.
- **Разные победы или песочница.** Условия победы выбираются при создании партии; можно отключить все и просто играть.

## Принципы

- **Шаги по 0.001.** Каждая версия — одна небольшая видимая возможность, рабочая игра, тесты, коммит и тег. После 0.999 идёт 1.000 — и дальше так же.
- **Данные отдельно от кода.** Расы, юниты, местность, технологии будут расти без конца, поэтому со временем переедут из таблиц в коде в файлы данных.
- **Сохранения живут годами.** Как только появится сохранение, у формата будет версия, а старые сохранения будут загружаться в новых версиях игры.
- **Песочница должна быть интересной сама по себе** — без цели победы. Это требует глубоких систем: экономика, дипломатия, события.
- **Расширять, а не переписывать.** Системы проектируются так, чтобы к ним добавлялось новое.

## Этапы

| | Этап | Что входит | Версии |
|---|---|---|---|
| ✅ | **1. Карта** | окно и цикл, гексы, камера, местность, генерация, русский шрифт | 0.001–0.008 |
| ⏳ | **2. Юниты и ходы** | юнит, выбор, перемещение, очки движения, ходы, поиск пути, несколько юнитов, туман войны | 0.009–0.020 |
| | **3. Города** | поселенец основывает город, границы, население и рост, производство юнитов, первые здания | ~0.021–0.045 |
| | **4. Экономика** | еда / производство / золото с клеток, ресурсы, рабочие и улучшения, дерево технологий древности; данные — в файлы | ~0.046–0.080 |
| | **5. Расы** | описание рас, черты и бонусы, уникальные юниты, выбор расы игроком | ~0.081–0.095 |
| | **6. Соперники** | несколько игроков разных рас под управлением ИИ, бой, захват городов, базовый ИИ | ~0.096–0.140 |
| | **7. Полная партия** | условия победы (несколько, на выбор) и песочница, главное меню, настройки новой игры, сохранение и загрузка | ~0.141–0.170 |
| | **8. Эпохи** | древность → античность → средневековье → … → современность: технологии, юниты, здания каждой эпохи | дальше |
| | **9. Космос** | выход на орбиту, другие планеты, звёздная карта, колонизация | дальше |
| | **10. И дальше** | эпохи после космоса | дальше |

Параллельно со всеми этапами, всегда:
- **Глубина** — дипломатия, торговля, культура, события, чудеса, характеры лидеров, ИИ умнее.
- **Полировка** — спрайты вместо фишек, звук и музыка, интерфейс, обучение, баланс, скорость на больших картах.

**Первая законченная партия** (против ИИ, от старта до победы или в песочнице) — конец этапа 7, ориентировочно 150–200 шагов.

## Открытые вопросы

- Какие расы: фэнтези (эльфы, гномы, орки…), инопланетные виды или полностью свои? — решить к этапу 5.
- Длительность партии и размеры карт — будут настройкой новой игры (этап 7).
